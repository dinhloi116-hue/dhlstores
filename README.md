# Shopee Workflow — Google AI Studio

Prototype full-stack cho Google AI Studio Build mode.

- Gemini: đọc ảnh/PDF, chuẩn hóa sản phẩm, gợi ý ngành, SEO.
- Code: giá vốn, phí Shopee, x9.000, SKU, export.
- Khối lượng tính cước không bị AI ghi đè.
- Ảnh bìa: prompt chung cho toàn bộ listing.
- Template Shopee được nạp từ trình duyệt và dùng khi export.

Import vào Google AI Studio: Build → Add files (+) → Import from GitHub → chọn repo này, branch `shopee-ai-studio`.
