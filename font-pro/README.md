# Font Pro Studio

Tool chỉnh font / dấu tiếng Việt chạy trực tiếp trên Chrome.

## File chính
- `font-pro/index.html` — bản đang dùng hiện tại.
- `font-pro/CHANGELOG.md` — lịch sử cập nhật.
- `font-pro/CAP_NHAT_TOOL.bat` — kéo bản mới từ GitHub rồi mở bằng Chrome.

## Cách dùng trên Windows
1. Clone repo `dinhloi116-hue/dhlstores` về máy một lần.
2. Vào thư mục `font-pro`.
3. Double-click `CAP_NHAT_TOOL.bat`.
4. File sẽ tự chạy `git pull` rồi mở `index.html` bằng Chrome.

## Quy ước cập nhật
Từ các bản sau, file chính luôn giữ tên `index.html`. Không tạo V30/V31/V32 thành nhiều file rời trong thư mục sử dụng.
